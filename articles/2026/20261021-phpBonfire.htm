PHP Critical Remote Code Execution Vulnerability

21st October 2026

It is the season for bonfires, after all, and this week has been one of those weeks the security industry gazes on the growing flames and wonders when the world will stop pouring petrol on the flames...

PHP announced updates (8.5.12, 8.4.27, 8.3.36 and 8.2.35) to fix two critical vulnerabilities that can allow unauthenticated remote code execution. All PHP users are strongly encouraged to update immediately (the NCSC went one further to suggest if patching is not possible, take the systems offline).

Two CVE's are tracked against this one - CVE-2026-109618 (RCE via RFC 1867 input parsing OOM) and CVE-2026-109619 (RCE via global state corruption after fatal error).

"There are no complete mitigations, updating is the only safe choice", states the PHP website, as exploits will be in full swing now across the Internet.

The PHP Site has more detail starting to flow in related to this critical issue.
