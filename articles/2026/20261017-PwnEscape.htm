PwnEscape Linux Kernel Flaw

18th October 2026

A critical flaw in the Linux kernel allows code within a virtual machine to read memory on the host computer it operates on. Tracked as CVE-2026-99999 with the PwnEscape nickname and rated at 9.3, lives in the kernel's networking code so it allows access to the shared layer cloud providers use to keep customer workloads separated.

The flaw was discovered in a Vercel security challenge by Paulos Yibelo of security company pwn.ai

Paulos found that the bug could read the host's memory, crash the host and run code on it. A fix is available in kernel branches, but these must be applied to your distro if not already merged into the main branch.
